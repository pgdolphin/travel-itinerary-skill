# Travel Itinerary Skill

一个面向同行朋友的沉浸式旅行攻略与行程分享产品。它不只罗列时间表，而是通过场景图片、章节导航、动效和关键行动信息，让没有参与攻略的人也能提前理解旅途中会经历什么。

## 当前实例

仓库目前收录首个完整实例：**象山石浦两天一晚 · 出海海钓与拖网之旅**。

内容包括：

- 两天一晚的完整时间安排
- 酒店、沙滩落日、渔港夜游等场景预览
- 包船、海钓、拖网和鲜捞海货加工体验
- 登船码头、停车、返程高铁等行动信息
- 面向手机浏览的沉浸式交互页面

## 项目结构

- `dist/index.html`：可直接部署的静态页面
- `dist/assets/`：页面所需图片素材
- `.openai/hosting.json`：现有 Sites 发布配置

## 产品方向

后续将把当前单次行程沉淀为可复用的旅行攻略生成与分享能力，让不同目的地、不同出行人群都能快速生成具有画面感、可执行、方便转发的行程页面。
